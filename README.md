# Trabalho em grupo — Listas Circulares

Projeto desenvolvido para a disciplina de **Estrutura de Dados**, ministrada pelo professor Douglas.
O objetivo do trabalho é implementar uma estrutura de dados do tipo **Lista Circular**, utilizando a linguagem C

## Funcionalidades do projeto

O programa implementa as seguintes operações:

- [ ] Inserir elemento no início da lista.
- [ ] Inserir elemento no final da lista.
- [ ] Remover elemento do início da lista.
- [ ] Remover elemento do final da lista.
- [ ] Exibir os elementos da lista.
- [ ] Buscar um valor e atualizá-lo.
- [ ] Liberar a memória utilizada pela lista.
